# Análise de código: folha de previsões (M01)

A análise de código treina a habilidade mais cobrada na prova: **executar o código de cabeça**.

## Como fazer

1. Abra o arquivo `A0x_*.java` e escreva **a sua previsão** para cada marcador `P1`, `P2`... na coluna "Previsão".
2. Só depois execute: `java --source 11 A0x_*.java` (modo arquivo-fonte do Java 11, sem precisar de `javac`).
3. Preencha "Real" e "✅/❌". Para cada ❌, escreva na coluna "Regra" **com suas palavras** a regra que você não aplicou.
4. Copie as regras erradas para o [Caderno de erros](../../../CADERNO-DE-ERROS.md).

> Aqui conferir executando o código é permitido, porque o objetivo é calibrar a intuição.
> No **simulado** isso é proibido.

**Pontuação de referência:** 72 marcadores. Meta para o nível de especialista: ≥ 65 acertos (90%).
