# Glossário EN → PT para a prova

As provas da Oracle são em inglês e repetem as **mesmas estruturas de frase**. Domine este vocabulário e metade da
dificuldade de leitura desaparece. Revise toda sexta-feira e acrescente os termos novos que aparecerem nos simulados.

## Como as perguntas começam

| Inglês | Português | Observação |
|---|---|---|
| *Given:* | Dado o código: | Introduz o trecho de código |
| *What is the result?* | Qual é o resultado? | Pode ser saída, erro de compilação **ou** exceção |
| *What is the output?* | Qual é a saída? | Normalmente o código compila e roda |
| *Which statement is true?* | Qual afirmação é verdadeira? | |
| *Which two statements are true? (Choose two.)* | Quais duas afirmações são verdadeiras? (Escolha duas.) | Sem crédito parcial |
| *Which code fragment, when inserted at line n1, ...* | Qual fragmento de código, inserido na linha n1, ... | |
| *...enables the code to compile?* | ...faz o código compilar? | |
| *...each applied independently* | ...cada uma aplicada isoladamente | As alternativas não se somam |
| *Assume that...* | Assuma/considere que... | Premissa que você deve aceitar |
| *How many objects are eligible for garbage collection?* | Quantos objetos estão elegíveis para coleta de lixo? | Tema do M03 |

## Como as alternativas são escritas

| Inglês | Português |
|---|---|
| *Compilation fails.* | A compilação falha. |
| *The code compiles but throws an exception at runtime.* | O código compila, mas lança uma exceção em tempo de execução. |
| *A `NullPointerException` is thrown.* | Uma `NullPointerException` é lançada. |
| *followed by* | seguido de |
| *The program prints nothing.* | O programa não imprime nada. |
| *The program hangs / never ends.* | O programa trava / nunca termina. |
| *The result is unpredictable.* | O resultado é imprevisível. (comum em concorrência) |
| *None of the above.* | Nenhuma das anteriores. |

## Verbos que mudam o sentido da pergunta

| Inglês | Português | Cuidado |
|---|---|---|
| *must* | deve (obrigatório) | |
| *may / can* | pode (permitido) | *may* não significa *must* |
| *always / never* | sempre / nunca | Basta um contraexemplo para a afirmação ser falsa |
| *at least / at most* | no mínimo / no máximo | |
| *only* | somente | |
| *guaranteed* | garantido | Comum em concorrência e GC: quase nada é garantido |
